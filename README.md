# Projeto: Desenvolvimento de Plataformas Web

Aplicação Web desenvolvida como requisito de avaliação da disciplina **Desenvolvimento de Plataformas Web** da **Universidade de Fortaleza (UNIFOR)**.

## 📌 Escopo do Projeto
Sistema Web para gestão de **Cardápio Digital** (marmitaria) com operações de **CRUD** (incluir, listar, alterar e excluir pratos com nome, descrição e preço), validação de campos obrigatórios, estado para lista vazia e persistência via `json-server` (`db.json`).

## 🛠️ Tecnologias Utilizadas
* **Front-end:** ReactJS, HTML5, CSS3, Bootstrap, Axios
* **Back-end / Persistência de Dados:** Node.js, `json-server` (`db.json`), `concurrently`
